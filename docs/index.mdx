## Connection details

| Setting | Value |
| --- | --- |
| Server URL | `https://cmr.earthdata.nasa.gov/mcp/v1` |
| Transport | Streamable HTTP |
| Server authentication | None |

Downloading data can require a separate Earthdata Login account. See the
[user guide's authentication section](/earthdata-mcp/consumers/earthdata-mcp-server-user-guide/#authentication).

## Development

The server is maintained at
[nasa/earthdata-mcp](https://github.com/nasa/earthdata-mcp). The
[developer guides](https://github.com/nasa/earthdata-mcp/blob/main/docs/README.md)
